# 巧未来·波龙量化 v1.6（quant-aio v3.0.0）

> A股 / ETF / 期货 / 期权全链路量化工作台 · 全部真实数据，零模拟、零随机数
>
> GitHub：https://github.com/SimonsTang/bowlong-quant-trading ｜ ClawHub 技能名：`quant-aio`

研究层借鉴 TSP 的统一口径、防未来函数与折外稳健分机制，并补足旧仓库缺失的**实盘执行、多市场、多品种、机构合规、AI 助手、专业 Web 终端与 GitHub 策略借鉴**，形成从数据 → 选股 → 回测 → 组合 → 风控 → 合规 → 实盘意图的完整团队工作流。

## 一、核心原则

1. **真实数据优先**：东财 / 腾讯 / 新浪三源降级，失败明示或降级到标注缓存（STALE / degraded），绝不伪造价格。
2. **无前视偏差**：T 日收盘产生信号，T+1 开盘成交；回测与实盘共用同一 `StrategyEngine`。
3. **稳健参数选择**：K 段折外评分 `0.6×中位数 + 0.4×最差段`，避免样本内最优过拟合。
4. **实盘边界清晰**：`validate` / `paper` / `live` 严格隔离，连接失败抛错，绝不明转模拟。

## 二、快速开始

### Windows 一键启动

双击根目录 `start.bat`。脚本会自动探测 Python（优先便携运行时），检查端口占用；服务已在运行则直接打开浏览器。

### 命令行启动

```bash
python web/server.py
# 浏览器打开 http://127.0.0.1:8765
```

仅用 Python 3.9+ 标准库，零第三方依赖。服务关闭：关闭终端窗口。

### 首次配置

打开 Web 终端左侧「系统配置」，依次配置：运行模式、AI 接口、数据源、回测参数、风控、合规、执行网关、选股因子、通知。密钥本地保存且界面脱敏；可用环境变量覆盖，例如：

```bash
QIAO_AI__API_KEY=你的密钥
QIAO_AI__BASE_URL=https://api.deepseek.com/v1
QIAO_AI__MODEL=deepseek-chat
```

仓库内 `config/system.json` 是**已清空密钥的模板**，请填入自己的配置，勿将真实密钥提交到公开仓库。

## 四、策略与实测结论

**13 个交易择时策略**：双均线、MACD、海龟突破、Dual Thrust、ATR 通道、布林回归、RSI、KDJ、N 日动量、双动量轮动、多因子、配对交易、网格交易。

**10 个选股策略**：价值、成长、动量、反转、质量、低波、资金流、多因子、小盘、技术面。

诚实实测（详见 `reports/`）：

- Dual Thrust 在沪深300ETF 十年真实前复权数据下 −12.49%，买入持有 +43.1%，36 组参数中位数 −3.4%。旧版本 +3258% 属前视偏差，已修正。
- 正确十年数据下 11/13 策略平均为正，但多数跑输茅台买入持有 +395%；网格 −39%，多因子/配对不适合单标的。
- ETF 动量轮动（22 日动量、N=20~22）十年 +327.7%、年化 15.6%、回撤 −25.7%、夏普 0.59；样本外含纳指/黄金大牛成分，需打折看待。
- 小市值因子受 2024 新国九条制度影响，北向实时因子因 2024-05-13 披露规则变化失效。

## 七、能力边界

- 免费源无生产级 SLA；高频、五档深度、机构级合规需商业数据与柜台环境。
- 不做 AI 荐股，不承诺收益；历史回测不代表未来。
- 港股实盘未接入；CTP 与期权实盘需相应柜台参数。
- 实盘需人工复核；策略退役、回撤熔断触发后必须人工确认重启。
